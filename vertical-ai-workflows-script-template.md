- Short punch clauses: “Ready, set, go.” / “Pretty sick.” / “Now we’re cooking.”
- Spoken UI narration: every click is voiced (“type Gemini, one word”).
- Empathy cushions before complexity: “Don’t be scared.”
- Contrast pairs: browser vs terminal, scattered chats vs one folder, vendor lock-in vs “I own my context.”
- Numeric stakes: “10× faster,” “20 chats,” “99% context left,” “85k → 88k tokens.”

## 3. Transferable structural formulas

### Formula α — Accusation → Demo → Escalation (NetworkChuck spine)
`STATUS ATTACK → PAIN MIRROR → DEFER OBJECTIONS → EASY WIN DEMO → POWER FEATURE → MULTI-AGENT MADNESS → SYSTEM SYNC → SOFT CTA`

### Formula β — Filter → Tip Ladder → Identity Payoff (Iman spine)
`POLARIZING FILTER → PROMISE MAP → TIP BLOCKS (why→story→steps→bridge) × N → ADVANCED CAPSTONE → IDENTITY CTA`

### Formula γ — Economics Rebuild (agency/team spine)
`$ OR HOURS BASELINE → OLD PROCESS AUTOPSY → SYSTEM NAME → LIVE REBUILD → LIMITS → ACTION PLAN`

**Best hybrid for Vertical AI Workflows (faceless):** **γ opening economics + α live escalation + β numbered chapters.**

## 4. Modular faceless script template

**Format:** Screen recording + voiceover (no face).  
**Target length:** 10–14 minutes (high retention band for tutorial workflows).  
**Speech rate:** ~145–160 wpm.  
**Visual rule:** Something meaningful changes on screen every 3–5 seconds during demos.

### Timing map (12:00 default)

| Module | Time | Retention job |
| --- | --- | --- |
| M0 Cold open | 0:00–0:20 | Pattern interrupt + unfinished result |
| M1 Hook + loops | 0:20–0:55 | Promise + 3 open loops |
| M2 Pain mirror | 0:55–1:40 | Viewer self-recognition |
| M3 Stakes + baseline | 1:40–2:20 | Timer / $ / error cost |
| M4 Easy win demo | 2:20–4:00 | First micro-win (cognitive reset) |
| M5 Core rebuild | 4:00–7:30 | Main workflow (2–3 steps) |
| M6 Power escalate | 7:30–9:20 | “Not even the best part” upgrade |
| M7 Failure honesty | 9:20–10:20 | Trust + novelty |
| M8 Final timed win | 10:20–11:20 | Payoff all loops |
| M9 Close + CTA | 11:20–12:00 | Artifact + next video loop |

### Fill-in script (placeholder lines calibrated for faceless narration)

#### M0 — Cold open (0:00–0:20)
**On screen:** Finished output already visible (report, CRM fields, listing pack). Cursor idle.  
**VO:**
> “This [DELIVERABLE] used to take me [OLD_TIME]. Watch the clock — we’re doing the whole thing in [NEW_TIME], no face, no fluff, just the workflow.”

**Technique:** Pattern interrupt + stakes seed.

#### M1 — Hook + open-loop stack (0:20–0:55)
**VO:**
> “If you’re still [WRONG_DEFAULT] for [PROFESSION_TASK], you’re doing it the slow way.  
> In the next [RUNTIME], I’ll show you: one, the exact prompt stack; two, the QA gate that stops confident wrong answers; and three, the reusable template you can run every [CADENCE].  
> Stick around for number three — that’s the piece most ‘AI tip’ videos skip.”

**Technique:** Contrast + open-loop stacking (3 loops).

#### M2 — Pain mirror / objection intercept (0:55–1:40)
**On screen:** Ugly montage — 8 chat tabs, copy-paste into Notion, red X on wrong output.  
**VO:**
> “You’re thinking: ‘I already use ChatGPT.’ Do you? Be honest.  
> You’ve got five chats, two half-finished prompts, and a result you’d never send to a client without rewriting.  
> That mess isn’t a you-problem. It’s a workflow-problem.”

**Technique:** Objection intercept + contrast framing.

#### M3 — Stakes amplification + baseline (1:40–2:20)
**On screen:** Big timer. Manual steps listed 1–2–3.  
**VO:**
> “Baseline. Same [INPUT]. Same quality bar. Manual path: [OLD_TIME], [OLD_COST_OR_ERRORS].  
> Remember that number. Everything after this is measured against it.”

**Technique:** Stakes amplification; sets pay-off metric.

#### M4 — Easy win demo (2:20–4:00)
**On screen:** One clean screen recording; zoom on critical clicks.  
**VO:**
> “Step one — the smallest win. Open [TOOL]. Paste this.  
> Don’t customize yet. Run it once.  
> There — [MICRO_OUTPUT]. That alone usually saves [MICRO_TIME].  
> If you stopped here, you’d already be ahead of most people. We’re not stopping.”

**Line pattern:** Spoken UI + micro-win + re-hook.

#### M5 — Core rebuild (4:00–7:30)
Break into **2–3 labeled substeps** (on-screen chapter cards).

**Substep template (repeat):**
> “Next, we [ACTION] so the model stops [FAILURE_MODE].  
> Watch what happens when I add [CONSTRAINT / EXAMPLE / RUBRIC].  
> Pause on this line — this is the lever.  
> Output: [BETTER_OUTPUT]. Still not client-ready. Good. That means the next gate matters.”

**Every ~90 seconds insert a re-hook:**
> “But this still breaks when [EDGE_CASE] — that’s coming up.”

**Technique:** Strategic reveals; open loops between substeps; cognitive resets via chapter cards.

#### M6 — Power escalate (7:30–9:20)
**VO:**
> “Here’s the part most tutorials never show.  
> We don’t ask one model to do everything. We split roles: [ROLE_A] drafts, [ROLE_B] checks, [ROLE_C] formats.  
> Same folder. Same inputs. No copy-paste gymnastics.  
> This is where [PROFESSION] work stops feeling like prompting — and starts feeling like a system.”

**Technique:** Escalation; status upgrade; system naming.

#### M7 — Failure honesty / trust beat (9:20–10:20)
**On screen:** Deliberate bad output → checklist catching it.  
**VO:**
> “Important: this will still lie confidently about [RISK_AREA].  
> So we add a hard gate — [QA_CHECK_1], [QA_CHECK_2], [QA_CHECK_3].  
> If any gate fails, the draft does not ship.  
> That single rule is what makes this safe for real [CLIENT/FILE/PATIENT-ADJACENT] work.”

**Technique:** Trust via limits; pattern interrupt from hype.

#### M8 — Final timed win (10:20–11:20)
**On screen:** Full run, timer in corner, final artifact.  
**VO:**
> “Full pipeline. Start to finish.  
> Old way: [OLD_TIME]. New way: [NEW_TIME].  
> Loop one — prompt stack — paid off.  
> Loop two — QA gate — paid off.  
> Loop three — reusable template — downloading to your brain right now: save this as [FILE_NAME] and rerun it every [CADENCE].”

**Technique:** Close open loops in order; numeric payoff.

#### M9 — Close + CTA (11:20–12:00)
**VO:**
> “If you want the [PROMPT_PACK / CHECKLIST] exactly as shown, [CTA_MECHANIC: comment keyword / link].  
> Next, I’ll show the version for [ADJACENT_WORKFLOW] — that’s where the time savings compound.  
> Run this once today on a real file. Not a demo file. A real one.”

**Technique:** Artifact CTA + new open loop to next video.

## 5. Section-by-section writing guidance (faceless)

1. **Never open with channel greeting.** Winners open mid-claim or mid-result.
2. **Narrate the cursor.** If the viewer can’t hear what to click, retention dies on mobile.
3. **One idea per sentence.** Faceless VO can’t rely on facial emphasis — rhythm is the emphasis.
4. **Stack loops early, pay them late — in order.** Unpaid loops feel like bait; scrambled payoff feels messy.
5. **Put a human failure in the middle.** Permission prompts, wrong drafts, cost blowups — these are retention, not mistakes.
6. **Name the system.** “The Invoice Exception Stack,” “The Listing 11,” etc. Named systems are memorable and series-friendly.
7. **End on an action with a real input.** “Use a real client file” beats “thanks for watching.”

## 8. Quality bar (reject list)

Do **not** ship a draft if it includes:
- “Hey guys, welcome back”
- Generic “AI is changing everything” throat-clearing
- Tool tour without a timed baseline
- More than 20 seconds without a visual state change
- A promise in the intro that isn’t paid off on-screen
